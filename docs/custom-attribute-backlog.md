# Custom Attribute Backlog

记录暂不接入（或延后接入）的 `TCardConditionalAttribute` 语义，避免后续重复排查。

## 已确认暂缓

1. 幸运三叶草  
- 原因：非战斗物品，暂不纳入实验室模拟。

2. 陷阱装置  
- 当前识别：`Custom_0`  
- 语义：对手物品第一次行动触发（对手侧首轮逻辑）。  
- 原因：涉及对手侧状态机，先暂缓。

3. 陷坑  
- 当前识别：`Custom_0`  
- 语义：与陷阱装置同类（对手侧首次行动触发）。  
- 原因：同上，暂缓。

4. 吉利服  
- 当前识别：`Custom_0`  
- 语义：复杂触发（暴击/减速关联），暂不优先。  
- 原因：复杂度高，延后。

5. 原木陷阱  
- 当前识别：`Custom_0`  
- 语义：对手侧触发。  
- 原因：对手侧状态逻辑，暂缓。

6. 银河翻译器  
- 当前识别：`Custom_0`  
- 原因：非战斗物品，暂不纳入实验室模拟。

7. 自力更升靴  
- 当前识别：`Custom_1`  
- 原因：非战斗物品，暂不纳入实验室模拟。

## 已接入

1. 划艇  
- 当前识别：`Custom_1 >= 7`  
- 语义：当场上“可见类型标签”总数 >= 7 时，冷却缩短 5 秒。  
- 说明：仅统计可见 `tags`（如 `Tool/Weapon/Vehicle/...`），不统计 `hidden_tags`，不统计尺寸标签。
